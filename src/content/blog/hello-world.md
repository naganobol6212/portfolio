ポートフォリオサイトを公開しました。これからのキャリアの記録と、学習・開発で得た知見をここに残していきます。

## なぜ Astro なのか

選定で比較したのは、Next.js / Astro / 素の HTML の 3 つです。

- **表示速度**: Astro はデフォルトで JavaScript をほとんど送らないため、Lighthouse スコアが高く出やすい。
- **ブログ運用**: Markdown / MDX を一級市民として扱える。Content Collections の型安全性が便利。
- **学習コスト**: HTML/CSS にコンポーネントの概念を足しただけの感覚で書ける。

将来 API ルートが必要になったら、Cloudflare Pages Functions または別途 Hono などで足す方針です。

## これから書く予定のこと

- 個人開発で踏んだ落とし穴と、その対処
- Rails と Next.js を行き来する中で見えてきた共通点 / 相違点
- 「課題の本質を掘り当てる」をエンジニアリングで実践する話
